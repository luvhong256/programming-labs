## Краткие теоретические сведения
* **Модуль в Python** — это отдельный файл с расширением `.py`, содержащий определения функций, переменных и классов, обеспечивающий повторное использование кода.
* **Импорт:** Форма `from module import function` позволяет подключать конкретные функции из пользовательских или системных модулей напрямую в текущее пространство имен.
* **Точка входа** `if __name__ == '__main__':` применяется для отделения основного исполняемого кода скрипта от логики функций при его импорте другими модулями.
* **Списки (list)** — упорядоченные динамические изменяемые массивы элементов произвольных типов.
* **Срезы (`[start:stop:step]`)** позволяют извлекать фрагменты последовательностей, где `start` — начальный индекс (включительно), а `stop` — конечный индекс (не включительно).
* **Системный список `sys.argv`** хранит аргументы командной строки. Элемент `sys.argv[0]` всегда содержит имя запускаемого скрипта, а последующие индексы — переданные из консоли параметры.

## Задание
**Физический процесс / инженерное явление:** При подаче ступенчатого сигнала на входе замкнутой САУ регистрируется переходный процесс. Инженеру необходимо проредить временной ряд для построения компактного графика, вычленить установившийся режим и построить словарь показателей качества.

* `extract_subsample(time_series, step=2)` — прореживает временной ряд с помощью среза `[::step]`;
* `find_settling_time(time_series, target_val=1.0, tol=0.05)` — определяет индекс первого вхождения сигнала в 5%-ю зону допуска;
* `build_summary_dict(time_list, signal_list)` — формирует сводный словарь показателей процесса (`overshoot`, `settling_time`).

## Исходный код программы

### 1. Пользовательский модуль `lab3_mod_variant15.py`
```python
def extract_subsample(time_series, step=2):
    return time_series[::step]

def find_settling_time(time_series, target_val=1.0, tol=0.05):
    lower_bound = target_val * (1 - tol)
    upper_bound = target_val * (1 + tol)
    settling_idx = -1
    for i in range(len(time_series) - 1, -1, -1):
        if not (lower_bound <= time_series[i] <= upper_bound):
            settling_idx = i + 1
            break
    if settling_idx == -1:
        settling_idx = 0
    if settling_idx >= len(time_series):
        return -1
    return settling_idx

def build_summary_dict(time_list, signal_list):
    max_val = max(signal_list)
    target_val = 1.0
    overshoot = max(0.0, (max_val - target_val) / target_val * 100)
    settling_idx = find_settling_time(signal_list, target_val=target_val)
    settling_time = time_list[settling_idx] if settling_idx != -1 else "Не установлено"
    return {
        'max_value': round(max_val, 3),
        'overshoot_percent': round(overshoot, 2),
        'settling_index': settling_idx,
        'settling_time': settling_time
    }
```

### 2. Главный исполняемый скрипт `main.py`
```python
import sys
from lab3_mod_variant15 import extract_subsample, find_settling_time, build_summary_dict

def main():
    signal = [0.0, 0.4, 0.9, 1.25, 1.1, 0.98, 1.02, 1.0, 1.01]
    time_mesh = list(range(len(signal)))
    step = int(sys.argv[1]) if len(sys.argv) > 1 else 2
    
    sub_signal = extract_subsample(signal, step=step)
    metrics = build_summary_dict(time_mesh, signal)
    
    print("=== АНАЛИЗ ПЕРЕХОДНОГО ПРОЦЕССА САУ ===")
    print(f"Заданный шаг прореживания (sys.argv): {step}")
    print(f"Исходный ряд сигналов: {signal}")
    print(f"Прореженный ряд (срез [::{step}]): {sub_signal}")
    print("\nПоказатели качества управления (Словарь):")
    print(f" - Максимальное значение: {metrics['max_value']}")
    print(f" - Максимальное перерегулирование: {metrics['overshoot_percent']} %")
    print(f" - Индекс времени установления: {metrics['settling_index']}")
    print(f" - Время установления: {metrics['settling_time']}")

if __name__ == '__main__':
    main()
```
