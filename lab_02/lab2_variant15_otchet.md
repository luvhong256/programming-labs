Предстоит изучить синтаксис и практическое применение в Python условных операторов (`if-elif-else`), циклов (`while`, `for..in`) и пользовательских функций (`def`). Необходимо овладеть приёмами построения алгоритмов управления, передачи аргументов и возврата результатов.

## 2. Краткие теоретические сведения
*   **Условный оператор `if-elif-else`** проверяет логические условия и организует ветвление. Благодаря `elif` несколько проверок выстраиваются в цепочку без лишних отступов. Блок `else` выполняется, если ни одно условие не истинно. Обязательны двоеточие (`:`) после условия и отступы (4 пробела).
*   **Цикл `while`** повторяет блок выражений, пока условие истинно (`True`). Для немедленного выхода используется `break`, для пропуска итерации — `continue`. При естественном окончании срабатывает необязательный блок `else`.
*   **Цикл `for..in` и функция `range()`** перебирают элементы последовательности (списки, строки, диапазоны). `range(start, stop, step)` создаёт арифметическую прогрессию, не включая `stop`.
*   **Пользовательские функции (`def`)** — это переиспользуемые именованные блоки кода. Функция объявляется через `def`, принимает параметры и возвращает результат оператором `return`. Docstrings (тройные кавычки) пишут сразу после заголовка для описания назначения.

## 3. Задание
Написать функцию `stepper_positioning(target_steps)`, моделирующую движение шагового двигателя в цикле. При остатке < 10 шагов уменьшать скорость в 2 раза. Функция возвращает суммарное время и число шагов.

## 4. Исходный код программы (Вариант 10: Заряд аккумулятора)
```python
def stepper_positioning(target_steps, start_speed=100.0):
    # текущая позиция сколько шагов пройдено
    current_step = 0
    # текущая скорость шагов/сек
    current_speed = start_speed
    # суммарное время
    summ_time = 0.0
    # моделируем движение, пока не дойдем до цели
    while current_step < target_steps:
        # вычисляем остаток пути
        ostatok = target_steps - current_step
        # если остаток меньше 10 шагов — уменьшаем скорость в 2 раза 
        if ostatok < 10:
            current_speed = start_speed / 2.0
        # делаем один шаг за интервал времени dt = 1 / speed
        dt = 1.0 / current_speed
        summ_time += dt
        # увеличиваем пройденное количество шагов
        current_step += 1
    return summ_time, current_step

# тестовые запуски 
test_cases = [
    (5, 100.0),  # замедляет сразу со старта
    (9, 100.0),  # граница почти сразу
    (10, 100.0), # ровно граница
    (25, 100.0), # обычная ситуация когда цель далеко
]

for target, speed in test_cases:
    t, steps = stepper_positioning(target, speed)
    print(f"\nЦель: {target} шагов, начальная скорость: {speed} шаг/с")
    print(f"  - Пройдено шагов : {steps}")
    print(f"  - Суммарное время: {t:.4f} с")
    print(f"  - Средняя скорость: {steps / t:.2f} шаг/с")
```

## 5. Результаты выполнения программы
При запуске написанного скрипта с параметром `target_steps = 25` программа моделирует движение шагового двигателя в цикле, отслеживая остаток пути и снижая скорость в 2 раза при остатке менее 10 шагов, и выводит итоговые значения в консоль: 

